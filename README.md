# Leggo - Online Flight Ticket Booking Service

Leggo is a responsive website that offers an online flight ticket booking service. Users can view and compare ticket options from multiple airlines by entering their travel details and selecting the desired ticket. The site is fully responsive, ensuring a seamless experience across desktops, tablets, and mobile devices.

## Features

- **Flight Search**: Users can search for flights by entering travel details such as destination, dates, and number of passengers.
- **Ticket Comparison**: Users can compare flights from various airlines and choose based on preferences like price, travel class, and round-trip or one-way tickets.
- **Booking and Order Management**: Users can book flights and view the details of their current orders.
- **Payment Integration**: Secure online payments are handled through Midtrans.
- **Responsive Design**: The website is fully responsive, adapting to desktops, tablets, and mobile devices.
- **Cloudflare Integration**: Integrated with Cloudflare for enhanced security and login functionality.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/Gumm11/Leggo.git
    ```

2. Set up the database using the provided schema.

3. Install dependencies using Composer:
    ```bash
    composer require midtrans/midtrans-php
    ```

4. Run the project on your local server.
